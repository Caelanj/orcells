Applicital

Phase 2

Applicital is an invented word which is for the axis that is perpendicular to both horizontal and vertical.
While horizontal goes from left to right and vertical goes from top to bottom, applicital goes from above to below.

It is based on this answer on stack overflow.
While in the stack overflow suggestion it is spelled "Applicatal" I got used to spelling it my way. I started using "Applicital" in the code without caring about their spelling, I spelled it auditorily because both spellings sound the same and it's a new word anyway, there is no official right way to spell it.
Feel free to start using the word because english really needs it.
