Type 1 Cell

Phase 1

Type 1 cells are the default type of cell.
Type 1 cells have one property: bit.
Bit is a boolean that can be on (1/true) or off (0/false).
You can see the state of the bit of a type 1 cell through it's colour which will either be black (off) or white (on).
